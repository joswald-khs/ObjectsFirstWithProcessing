# Creating a Shape Object and Making it Visible

> [!TIP]
> Remember, you need run `void main(String args[])` on the `Canvas` class before you start creating objects.

## Creating a Shape

1. Make sure that everything is compiled (no diagonal lines)
2. If you had to compile, you'll need to run `main(String args[])` again
3. Pick a shape and right/control click on it
4. Select `new <Whatever Shape You Selected>()`
5. Pick a name for the shape, or just click through
6. You should now see a red box in the object with its name
7. Make the shape visible

### Questions and Potential Problems

#### Why can't you see the shape? 

It could be a couple of things. When you run `main` an applet should start on your computer. That applet contains the drawing canvas. If you don't see that, you definitely won't be able to see the shape. Make sure you find it. 

If you can see the canvas, but not the shape, it probably means that the shape hasn't yet been made visible. 

There are other reasons you might not be able to see the shape. Perhaps you made changes to `Canvas` or to one of the shape classes that changed the canvas size or the location of the shape in such a way that it isn't visible. 

#### I made two shapes, and I can't see them both.

That's an interesting one! If you can see both shapes in BlueJ's object bench, but can only see one shape on the canvas, why do you think that is?

#### Does it matter what I name the shapes?

Maybe! Try different names. In the end, as long as you have a valid name (I don't think BlueJ will let you create an invalid name), it really doesn't matter.
