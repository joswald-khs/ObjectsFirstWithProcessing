# Growing or Shrinking a Shape

## Steps

1. Make sure that everything is compiled (no diagonal lines)
2. If you had to compile, you'll need to run `main(String args[])` again
3. [Create several shapes and make them visible](1.md).
4. [Move your shapes around](2.md) if you want
5. Change the size of your shapes
