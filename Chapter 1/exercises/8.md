# Working in `Canvas`

For any work of reasonable complexity, interacting with the shapes on the object bench is quite annoying. Let's address that now. 

## Steps

1. Open up the `Canvas` class. 
2. Find `public void settings()`
3. Change the values there, recompile, and run `main` to see a new canvas size.
4. Now, try to recreate the drawing you made in [part 5](5.md) (hopefully you did take notes!). To do this, you'll need to write the code for the steps you executed by hand. For instance:
   ```java
   public void setup() {
     myCircle = new Circle();
     myCircle.makeVisible();
     myCircle.changeColor("red");
     myCircle.moveHorizontal(10);
     shapes.add(myCircle) // <--- this step you didn't have to do before, but is critical that you do now! 
   }
   ```
6. Once you are done, take a screenshot of the final product and make sure to save your code!
